# v0.17.4-greeting.5 · 先图后文人工核对版

这是基于 [geekgeekrun/geekgeekrun](https://github.com/geekgeekrun/geekgeekrun) 的非官方二次开发版本。本版保留原有自动开聊等功能，增加首次开聊先发图片、再发固定文字，以及发送结果不确定时的人工核对与恢复。

## 下载哪个文件

- **Windows 用户**：下载 `GeekGeekRun-Greeting-0.17.4-greeting.5-setup.exe`，双击安装。
- **需要修改程序**：下载 `GeekGeekRun-Greeting-source.zip`，或在仓库中查看源码。
- **核对文件完整性**：下载 `SHA256SUMS.txt`，比对 SHA-256。

安装包适用于 Windows x64，安装后桌面入口为 **GeekGeekRun Image Greeting**，窗口左下角应显示 `0.17.4-greeting.5(46)`。

## 使用前要做什么

1. 在 BOSS 中关闭自带自动打招呼。
2. 打开程序，通过「编辑登录凭据」登录自己的账号并保存凭据。
3. 进入「自动开聊」，打开「首次开聊：先图片，后固定文字」。
4. 选择一张 PNG / JPG（不超过 10 MB），填写固定文字（不超过 1000 字）。
5. 设置职位条件，先检查内容，再点击「保存配置，并开始求职！」。

完整使用说明、截图、备份和换电脑步骤请看 [仓库 README](https://github.com/Onecki/geekgeekrun-image#readme)。

## 本版人工核对窗口

**发图二次确认失败，请人工核对**：图片已成功则只补文字；图片不存在则重走先图后文；图片转圈或失败则保持停止。

**对账不确定，请人工核对**：图文都成功则标记完成；仅图片成功则补文字；都未发送则重走先图后文。

选项会处理相应发送状态，并在允许恢复时继续当前任务，不用手改 JSON。关闭窗口或按 Esc 保留停止状态。

## 从旧版升级

先停止任务、退出程序，备份 `%USERPROFILE%\.geekgeekrun`，再运行安装包覆盖升级。同一 Windows 用户下默认沿用原数据目录，不需要先卸载。

安装包不携带个人数据。换电脑还需要迁移原数据，并重新检查登录、浏览器、图片路径及历史记录。
