# 牛人快跑「先图后文」二开版

版本：0.17.4-greeting.5（46），基于上游 0.17.4 源码。Windows x64。

本次新增两套人工核对弹窗，核对后直接在当前任务内恢复投递，不用手工修改 JSON 或重开程序。保留 .4 的残留锁恢复，以及中文输入、独立安装目录和后台连接等已有修复。

## 安装与数据

1. 停止投递并退出先图后文版，保留已完成的 `.geekgeekrun` 整目录备份。
2. 安装新版，桌面入口统一为 **GeekGeekRun Image Greeting**。默认安装目录为 `%LOCALAPPDATA%\Programs\geekgeekrun-greeting`，不需要先卸载原版。
3. 新版默认仍读取 `%USERPROFILE%\.geekgeekrun`，继承已有开聊记录、筛选配置和登录信息。登录失效时重新登录同一个 BOSS 账号。
4. 打开“开聊记录”检查原有记录及最近几条内容。安装包和源码中不包含个人投递记录、配置或登录凭据。
5. 原版与新版共享正式数据目录，使用时只运行其中一个。

## 使用

在“自动开聊”页面顶部打开“首次开聊：先图片，后固定文字”。默认关闭。

- 先在 BOSS 内关闭自带的自动打招呼。
- 选择 PNG/JPG 图片（不超过10MB）；程序会复制到自己的数据目录，原图移动不会影响发送。
- 填写固定文字（不超过1000字），保存配置。
- 首次使用先限定到少量明确目标，观察一位新招聘者的实际发送顺序，再继续批量运行。

新增流程：原有职位筛选 → 建立新会话 → 核对账号和招聘者 → 检查已有主动消息 → 上传图片 → 重新打开会话并核对服务器历史消息 → 发送固定文字 → 再核对服务器历史消息 → 继续原流程。

启用时先核对本程序记录的未完成发送，再加载当前账号的全部本地开聊记录以过滤历史会话。普通历史会话不补发图片或文字，不修改旧的开聊记录。新会话已经存在主动消息时会停止，以免破坏“第一条为图片”的要求。

## 异常处理

如果身份、图片上传、消息历史或网页结构无法确认，当前自动开聊任务会停止并弹出原因。发送进度保存在 `storage/first-greeting/`，独立于 `public.db`。

重新启动任务后，先从服务器历史核对未完成记录：图文已存在时直接标为完成；新版本记录明确证明图片已发送、文字尚未点击发送时，只补文字。已经尝试点击发送但服务器结果不明时停止，不盲目重试。旧版本缺少文字快照且服务器只有图片的记录，需要手动核对；不要删除进度目录重新发图。

### 发图二次确认失败，请人工核对

- A「图片已发送成功」：不重发图片，仅补发文字后继续投递。
- B「聊天中没有这张图片」：重新先发图片，再发文字，随后继续投递。
- C「图片转圈或显示发送失败」：保持暂停，先处理图片发送异常。

### 对账不确定，请人工核对

- A「图片和文字都已发送」：标记完成，继续下一个职位。
- B「只有图片已发送」：仅补发文字，成功后继续投递。
- C「图片和文字都未发送」：重新先发图片，再发文字，随后继续投递。

弹窗显示当前招聘者及标识。「打开当前聊天」只定位待核对的会话，不代表确认。关闭弹窗、按 Esc 或选择保持暂停，会结束当前投递任务并保留发送进度。确认前后都会检查账号和对象；一项选择仅授权本次立即恢复，补发中再次出现结果不确定时仍需核对。补发保留最初的固定文字快照，不会因修改配置而变成另一段文字。

服务器确认失败也可能发生在文字发送后，此时使用核对整套图文的第二套弹窗，不会错误显示“图片成功后补文字”的第一套选项。

异常退出遗留的锁由 .4 的进程验活逻辑自动接管；活跃任务仍阻止并发发送。不要删除整个发送进度目录来重试。

## 构建

本次环境：Node 24.15.0、pnpm 8.15.9、Electron 39.2.7。
浏览器测试使用本机 Chrome，或通过 `GEEKGEEKRUN_TEST_CHROME` 指定浏览器路径。

```powershell
$env:PUPPETEER_SKIP_DOWNLOAD = 'true'
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
npx --yes pnpm@8.15.9 install --frozen-lockfile
npx --yes pnpm@8.15.9 --dir packages/ui test:greeting
npx --yes pnpm@8.15.9 --dir packages/ui build:win
```

开发命令 `pnpm --dir packages/ui dev` 默认使用仓库同级的 `test-data` 独立目录；也可以通过 `GEEKGEEKRUN_DATA_DIR` 指定数据目录。正式安装版不设置此变量时沿用原目录。

自定义版禁用上游更新提示，避免用户误装官方版本后丢失新增功能。安装包采用独立应用名称与应用标识，并保留卸载时的用户数据。
